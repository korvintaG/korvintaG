## Публичная база знаний по методу Zettelkasten (FullStack-разработчик)
**Время работы над проектом**: 2024 г. — настоящее время

**Технологии**: Linux Ubuntu, Docker, PostgreSQL, TypeScript, Nest.js, Telegram API, HTML, CSS, React, Redux

**Описание**: Стартап публичной базы знаний по методу Zettelkasten. Дискуссии планируется организовывать по технологии, изложенной Мортимером Адлером. Мною реализован с нуля. Взаимодействие с Telegram сделала Светлана Зимина (https://github.com/szimina)

**Степень готовности**: реализована основа (FrontEnd и Backend). В ближайшее время планируется организация дискуссий по методу Мортимера Адлера.

**Особенности**:
- Авторизация через JWT access и refresh токен
- Регистрация новых пользователей через Telegram Bot
- Премодерация всей поступаемой от пользоваталей информации
- Использование в React компонентов высшего порядка
- Оценка идей в 3-х мерном пространстве с помощью специального компонента по правилам современной социологии
