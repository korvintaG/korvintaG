# 🚀 Портфолио: Мои проекты

## Публичная база знаний по методу Zettelkasten (FullStack)
**Время работы над проектом**: 2024 г. — настоящее время

**Технологии**: Linux Ubuntu, Docker, TypeScript, PostgreSQL, Nest.js, Telegram API, HTML, CSS, React, Redux

**Описание**: Стартап организации публичной базы знаний по методу Zettelkasten. Дискуссии планируется организовывать по технологии, изложенной Мортимером Адлером. Мною реализован с нуля. Взаимодействие с Telegram сделала Светлана Зимина (https://github.com/szimina)

**Степень готовности**: реализована основа (FrontEnd и Backend). В ближайшее время планируется организация дискуссий по методу Мортимера Адлера.

**Особенности**:
- Авторизация через JWT access и refresh токен
- Регистрация новых пользователей через Telegram Bot
- Премодерация всей поступаемой от пользоваталей информации
- Использование в React компонентов высшего порядка
