## Индивидуальная база знаний по методу Zettelkasten
**Время работы над проектом**: 2021 г. — настоящее время

**Мое участие**: Desktop-разработчик

**Технологии**: Delphi, GridEh, SQLite

**Описание**: Pet-проект индивидуальной базы знаний по методу Zettelkasten. Рекомендованный для этих целей Obsidian не понравился. Сделал для себя и своего коллеги.

**Степень готовности**: основа готова и успешно эксплуатируется, хотя есть еще куда расти.

**Особенности**:
- База хранится в SQLite, что позволяет производить мгновенный поиск по десяткам тысяч заметок
- Прикрепленные к заметкам и к источникам файлы хранятся вне SQLite как обычные файлы
- Встроенный Tag Commander позволяет удобно управлять более 10 000 ключевых слов, организованных иерархически
- Совмещает удобство иерархической файловой структуры и хранения в SQL-записях СУБД
